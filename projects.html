Michael's Collection · Curated Gallery

Interactive Web Application & Cosmic Digital Exhibition
Status: Completed

Michael's Collection is a signature interactive web project developed as part of the Web Design & Coding curriculum at Grossmont High School. Designed to unite advanced visual aesthetics with intuitive front-end architecture, the application immerses visitors in a dynamic cosmic starfield while presenting curated thematic cards celebrating personal interests, cultural roots, sports heroes, and world landmarks.

Technical Implementation

Behind The Code: Architecture & Performance

How Michael engineered the interactive mechanics, animations, and responsive layout for the collection.

🌌

Cosmic Roaming Starfield

Created using custom shader/canvas mathematics that render an infinite space background with floating stellar particles, providing a futuristic atmospheric ambiance.

💎

Dark Glassmorphism UI

Engineered with multi-tier translucent layers (rgba(15, 23, 42, 0.85)), background blur filters, and glowing light blue border highlights to ensure contrast and readability.

📱

Fluid Responsive Grid

Structured with CSS Grid auto-fit and minmax properties to dynamically adapt from mobile smartphone screens up to wide desktop monitors without breaking layout flow.

🔍

Interactive Modal System

Implemented with client-side JavaScript for instantaneous lightbox magnification, allowing visitors to inspect image details, tags, and descriptive captions.
